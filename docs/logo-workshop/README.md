# Hazel rabbit mark workshop

Six original, monochrome SVG directions for Hazel's Quickshell bar mark. Each
uses a `24 × 24` viewBox and is designed to survive Hazel's current `18 × 16`
logical-pixel slot. The production QML can colorize any of these through its
existing `MultiEffect`, so the source artwork stays white and theme-neutral.

- **Fork:** the clearest conventional rabbit silhouette, made less soft by split
  eyes and hard cheek planes.
- **Sentry:** one listening ear and one swept ear; alert without looking like a
  generic pet icon.
- **Sprint:** a low, kinetic profile with ears swept back.
- **Visor:** the most overtly cyberpunk direction; a single visor cut replaces
  small facial detail.
- **Warren:** an infrastructure emblem, enclosing the rabbit in a beveled cell.
- **Thorn:** an asymmetric, feral three-quarter mark with a projecting cheek.

`contact-sheet.svg` compares the marks enlarged and at the real bar footprint.
